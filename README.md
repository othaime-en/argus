**A fast, intuitive TUI dashboard for monitoring multiple CI/CD pipelines in real-time.**

Named after Argus Panoptes—the all-seeing giant from Greek mythology with a hundred eyes—this tool helps you watch over all your pipelines simultaneously.


## Development Status

ARGUS is currently in **Phase 1: Foundation** - establishing core infrastructure and basic TUI.
